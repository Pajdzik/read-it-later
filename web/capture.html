iPhone or iPad Shortcut

Use the Share menu to send a link directly to your private library. Create a token from Settings first. Keep the token in the Shortcut only; revoke it in Settings if you lose the device.

  1. In Shortcuts, create a shortcut named “Save to Potem” and enable it in the Share Sheet.
  2. Accept URLs and Safari web pages as input. Add “Get URLs from Shortcut Input” and choose one URL if the shared page contains several. Send one URL per request.
  3. Add “Get Contents of URL”; set the URL to , method to POST, and request body to JSON.
  4. Add header Authorization with value Bearer YOUR_CAPTURE_TOKEN.
  5. Set JSON keys url to the URL from the first action and title to the Shortcut Input’s name only when it is non-empty. Omit the key if blank.
  6. Show the result. A response with duplicate: true means the link was already saved. If the request fails, check the network and token.

Sharing plain text with several links is ambiguous. Open Potem and paste the one you want to save. iOS Shortcut support is the reliable mobile route; browser Share Target support varies.

Install Potem

On supported browsers, use the browser’s Install app or Add to Home Screen command. Installed browsers that support web share targets can send a shared link to the review form. Sharing never saves until you confirm.
